About DeepFake Analysis

AI-Based DeepFake Detection System using Deep Learning

Project Overview

DeepFake Analysis is a web-based Artificial Intelligence application developed to detect manipulated digital content such as images, videos, and audio recordings. The system uses Deep Learning models trained on real and fake datasets to identify whether uploaded media is authentic or AI-generated.

This project is developed as an AIML major project using Flask, TensorFlow, OpenCV, Librosa, and MySQL.

Project Objectives

Image Detection

Detect AI-generated and manipulated facial images.

Video Detection

Analyze video frames to identify DeepFake videos.

Audio Detection

Detect AI-generated voice recordings and fake speech.

Technology Stack

  • Backend : Flask (Python)

  • Audio Processing : Librosa
